# 开发阶段规划

1. Phase 1：项目初始化与运行环境
2. Phase 2：数据库、认证、权限与 RBAC
3. Phase 3：前端基础 UI 与主流程页面
4. Phase 4：资产中心与用户管理
5. Phase 5：扫描任务系统与任务队列
6. Phase 6：基础安全检测插件
7. Phase 7：规则引擎、评分与风险中心
8. Phase 8：AI 安全顾问
9. Phase 9：AI 安全报告
10. Phase 10：后台管理系统
11. Phase 11：大屏仪表盘与运营分析
12. Phase 12：Demo 数据与演示模式
13. Phase 13：UI 优化与交互增强
14. Phase 14：测试、文档、性能与安全加固

每个阶段都需进行：

- 代码运行检查
- TypeScript / Python 语法检查
- API 接口检查
- 数据库 migration 验证
- 对应功能验证与回归检查
